# MK20 B 硬件说明

MK20 Agent Deck 面向 Waveshare MK20 (B) 桌面小键盘。仓库中的主机守护进程、设备端程序和模拟器分别承担不同职责：

- 20 个带小屏的按键和一块副屏负责显示页面、会话状态和提示；
- Allwinner T113-S3 运行 Linux、设备监管程序、键盘渲染器、路由和可选的 agent 服务；
- GD32 键盘控制器负责按键和旋钮输入；
- 主机通过 USB 复合设备与键盘通信，包含网络链路、HID 和维护用 ADB 通道；
- `deck/mk20sim/` 和 `deck/mk20deck sim-*` 可以在没有设备时回放交互和生成键面图。

## 软件边界

主机端 `mk20deck` 负责会话状态、页面逻辑、渲染请求和需要主机权限的动作，例如截图。设备端负责屏幕绘制、输入采集、HID 输出、链路监管和 A/B 槽启动。协议和页面约束分别见 `deck/kbd/CTL-PROTOCOL.md`、`deck/kbd/UI.md` 和 `deck/docs/PRD-1.5-L1-LAYOUT.md`。

## 开发顺序

先运行主机测试和模拟器，再做 C UI / 设备端测试；只有在专用 Docker 环境中完成全量测试后，才考虑生成固件包。真实设备验收必须有备份、安装证据、soak 结果和可执行的回滚路径。

## 不可绕过的安全边界

- 不刷写 GD32，也不向 GD32 发送未经明确允许的命令；
- 不在设备上直接执行普通 `reboot`，按项目规定使用安全重启路径；
- 不让 ADB、USB 重枚举或网络切换操作影响其他 USB 设备；
- 不把设备密钥、主机凭据、摄像头密码或个人路径提交到仓库；
- 修改协议、固件安装流程或 GD32 相关代码前，先取得维护者明确批准。

完整规则和发布检查见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
