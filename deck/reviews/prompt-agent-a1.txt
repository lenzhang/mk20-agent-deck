   (second -> "busy"). Reply ok immediately. The keyboard side calls new `ctl_confirm_shown(c, now)` when the confirm page

   estop / disallow / requesting client gone -> pending confirm cancelled with reason. Result is pushed to the requesting
   client as `{"ev":"confirm.result","cid":..,"ok":true|false,"reason":".."}`. Expose pending state in `status`.
   Bound ctl_timeout_ms by the confirm deadline too. Unit tests in tests_ctl.inc for every case incl. 299/300 ms boundary.
