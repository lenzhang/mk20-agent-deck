+# MK20 Agent firmware: recovery
+
+Work from the top of this list down, and stop at the first level that works. Levels 1–3 need only adb, or a TF
+card reader if adb is gone. Level 5 needs the TF card in the Mac. Only the whole-card restore at the end of level 5
+writes the rootfs (p5) and the overlay (p6); everything else leaves them alone.
+(The P0 GD32/VIA backup and restore manual is `deck/RECOVERY.md`.)
+
+`$MK20_ADB` is `~/mk20-backup/mkadb.sh` (MK20 only, never the watch). "Reboot" always means one of:
+- `$MK20_ADB shell 'touch /mnt/SDCARD/cmd-reboot && sync'`: the watcher runs a hardreset through the WDT, about
+  30 s later; or
+- a USB power cycle (unplug and replug), which needs a human.
+
+Never use `reboot`: the soft reboot hangs on this board.
+
+## 0. Look first (read-only)
+
+```sh
+$MK20_ADB shell 'sh /data/mk20/rescue/loader.sh status'
+$MK20_ADB shell 'v=$(cat /data/mk20/state/good); /data/mk20/releases/$v/sbin/mk20d health'
+$MK20_ADB shell 'tail -n 30 /data/mk20/logs/mk20d.log /mnt/SDCARD/mk20/logs/loader.log /mnt/SDCARD/mk20/logs/watcher.log'
+$MK20_ADB shell 'cat /tmp/mk20/stub.status /data/mk20/state/hardreset.last /mnt/SDCARD/gadget-ecm-hid.status'
+python3 tools/mk20_host_net.py status       # Mac side: service, routes, device subnet, ping
+python3 tools/mk20_accept.py --no-hid       # read-only check (without --no-hid it also writes two all-released HID reports)
+```

+## 1. Flag files (FAT `/mnt/SDCARD/`, read at boot; then reboot)
+
+| flag | effect |
+|---|---|
+| `mk20-no-composite` | release runs in stock mode: ACM + KD (+adb), no ECM/HID/bridge |
+| `mk20-gadget-nohid` | composite without HID (ECM + ADB + bridge). Not a fix for the ep3 kernel: 1.1.x releases don't run on it at all (see level 5) |
+| `mk20-no-adb` | no adb in any mode |
+| `mk20-no-release` | loader skips releases: legacy `boot-every/` jobs only (stock + adb keeper) |
+| `mk20-no-watch` | boot stub does nothing at all: pure vendor behaviour, no rescue watcher, no adb |
+
+Over adb: `$MK20_ADB shell 'touch /mnt/SDCARD/mk20-no-composite && sync'`, then reboot. Without adb, **unplug the
+MK20 first** (rootfs and overlay live on the card), then put the TF card in the Mac (the FAT volume mounts in Finder), create the empty file, eject cleanly, and put the card back.
+Delete the flag to undo.
+
+Commands the watcher polls for every 2 s:
+- `cmd-reboot`: hardreset.
+- `cmd-rollback`: switch to the other A/B slot, then hardreset.
+- `cmd-ping`: replies "pong" on ttyGS0.
+- `job.sh` with `job.sh.sha256`: verified one-shot job, 300 s cap.
+
+## 2. Roll back the release
+
+- **Automatic:** a pending release that fails its self-test, fails composite setup during probation (1.1.1+), or
+  isn't confirmed within 600 s rolls back to `good` with at most one hard reset. Proven on hardware with 1.0.3
+  rolling back to 1.0.2.
+- **Manual:** `$MK20_ADB shell 'touch /mnt/SDCARD/cmd-rollback && sync'`. The watcher runs `loader rollback` and
+  then a hardreset. Over a shell, `sh /data/mk20/rescue/loader.sh rollback`, then reboot.
+- Afterwards, align the Mac: `python3 tools/mk20_host_net.py sync`. In a mismatch, the bound link-local path to
+  169.254.7.2 still works.
+
+- **Rollback once-guard (1.1.3+):** `gadget.sh --rollback-now` runs only once per composite (flapmon, the confirm
+  waiter and mk20d may all ask). It leaves `/tmp/mk20/rollback.once`; a new successful composite setup clears it.
+  From 1.1.4 it exits 0 only when stock is verified (ACM linked, UDC bound, KD running); otherwise it logs
+  "rollback NOT verified", releases the guard and exits 1, so a retry works. If a rollback process was killed
+  half-way, `rmdir /tmp/mk20/rollback.once` before re-running it by hand.

+#!/bin/sh
+# MK20 flap monitor (1.1.2+; was an inline heredoc in gadget.sh). Started detached by gadget.sh:
+#   flapmon.sh <udc-state-file> <window_s> <drops> <log> <stopfile> -- <rollback command...>
+# Counts link drops; >= <drops> within <window_s> -> touch the gadget.busy marker and run the rollback command once,
+# then exit. A drop is: configured -> anything but configured/suspended, or a SHORT suspend (< MK20_FLAP_SUSP_S,
+# default 5 s) that ends in anything but configured (a bus reset/glitch the poll caught as idle). A long suspend
+# (Mac sleep) is not a flap: suspend, resume and a resume reset / unplug after it are logged, not counted.
+# Single instance (flock on fd 8, not inherited by the rollback). The stopfile is re-checked right before rollback.
+# If the rollback command fails, the busy marker is cleared so mk20d does not wait on a dead failsafe.
+# Writes the ready marker (MK20_FLAP_READY, default /tmp/mk20/flapmon.ready) once the lock is held.
+# Test env: MK20_UPTIME_CMD (seconds), MK20_FLAP_POLL (default 0.3), MK20_BUSY, MK20_FLAP_LOCK, MK20_FLAP_SUSP_S.
+[ $# -ge 7 ] && [ "$6" = -- ] || { echo "usage: flapmon.sh state window drops log stopfile -- cmd..." >&2; exit 2; }
+U=$1; W=$2; N=$3; LOG=$4; STOP=$5; shift 6
+case "$W$N" in ''|*[!0-9]*) echo "flapmon: window/drops must be integers" >&2; exit 2;; esac
+BUSY=${MK20_BUSY:-/tmp/mk20/gadget.busy}; SUSP=${MK20_FLAP_SUSP_S:-5}
+LOCK=${MK20_FLAP_LOCK:-/tmp/mk20/flapmon.lock}; mkdir -p "$(dirname "$LOCK")"
+exec 8>"$LOCK"; i=0; while ! flock -n 8; do i=$((i+1)); [ $i -lt 10 ] && { sleep 0.5; continue; }
+  { echo "flapmon $(cut -d. -f1 /proc/uptime): another monitor holds $LOCK" >> "$LOG"; exit 3; }; done
+READY=${MK20_FLAP_READY:-/tmp/mk20/flapmon.ready}; mkdir -p "$(dirname "$READY")"; : > "$READY"   # lock held: gadget.sh waits for this
+up() { if [ -n "${MK20_UPTIME_CMD:-}" ]; then $MK20_UPTIME_CMD; else cut -d. -f1 /proc/uptime; fi; }
+prev=$(cat "$U" 2>/dev/null); times=""; sus=""
+while [ ! -f "$STOP" ]; do
+  s=$(cat "$U" 2>/dev/null); now=""
+  if [ "$s" != "$prev" ]; then
+    if [ "$prev" = configured ] && [ "$s" = suspended ]; then
+      sus=$(up); echo "flapmon $sus: host suspend" >> "$LOG"
+    elif [ "$prev" = configured ]; then
+      now=$(up)
+    elif [ "$prev" = suspended ]; then
+      t=$(up); d=$((t - ${sus:-$t}))
+      if [ "$s" = configured ]; then echo "flapmon $t: host resume after ${d}s" >> "$LOG"
+      elif [ -n "$sus" ] && [ "$d" -lt "$SUSP" ]; then now=$t
+      else echo "flapmon $t: '$s' after ${d}s suspend (resume reset/unplug, not counted)" >> "$LOG"; fi
+      sus=""
+    fi
+  fi
+  if [ -n "$now" ]; then
+    nt=""; cnt=0
+    for t in $times $now; do [ $((now-t)) -le "$W" ] && { nt="$nt $t"; cnt=$((cnt+1)); }; done; times=$nt
+    echo "flapmon $now: link drop ($s), $cnt in ${W}s" >> "$LOG"
+    if [ "$cnt" -ge "$N" ]; then
+      [ -f "$STOP" ] && exit 0
+      echo "flapmon $now: FLAPPING -> rollback" >> "$LOG"; touch "$BUSY"
+      "$@" 8>&-; rc=$?
+      [ "$rc" = 0 ] || { echo "flapmon $now: rollback command failed rc=$rc" >> "$LOG"; rm -f "$BUSY"; }
+      exit 0
+    fi
+  fi
+  prev=$s; sleep "${MK20_FLAP_POLL:-0.3}"
+done

+"""share/flapmon.sh (1.1.3): flaps roll back exactly once; long host suspend (Mac sleep) does not count."""
+import os
+import subprocess
+import time
+from pathlib import Path
+
+FM = Path(__file__).resolve().parents[1] / "firmware/release/share/flapmon.sh"
+
+
+def put(p: Path, text: str) -> None:
+    """Atomic write so flapmon never reads a truncated (empty) state."""
+    tmp = p.with_name(p.name + ".tmp")
+    tmp.write_text(text)
+    os.replace(tmp, p)
+
+
+def start(dev, tmp_path, window=60, drops=5, cmd=None):
+    st, log, stop, mark, clock = (tmp_path / n for n in ("state", "fm.log", "stop", "rolled", "clock"))
+    put(st, "configured\n"); put(clock, "100\n")

+#!/usr/bin/env python3
+"""MK20 hardware acceptance (M7). Runs on the Mac; needs MK20_ADB (MK20-only adb wrapper).
+
+  mk20_accept.py [--reboot] [--json OUT] [--no-hid]

+  adb shell; loader good==current, nothing pending; mk20d health status ok / composite / kd=1 / watchdog / selftest;
+  ping 172.30.250.2 via the MK20 interface; TCP to the bridge on the primary and on link-local 169.254.7.2 (both
+  bound to the MK20 interface); Protocol A getInfo over TCP (deviceVersion); HID: Mac sees the 1d6b:0104 keyboard
+  and two all-released reports written to /dev/hidg0 are consumed by the host within 5 s (detached, never killed); Mac route to the device not via a
+  TUN; FAT/mem headroom. --reboot first does one watcher hardreset (WDT) and checks hardreset.last fat_ro=y.
+Read-only apart from --reboot and the HID probe (two all-released keyboard reports; presses nothing).

+import json
+import os

+import time

+import tcp_transport as tt  # noqa: E402
+
+DEV_IP = os.environ.get("MK20_HOST", "172.30.250.2")
+LL_IP = "169.254.7.2"
+PORT = int(os.environ.get("MK20_BRIDGE_PORT", "17890"))

+class NoAdb(RuntimeError):
+    pass

+def adb_cmd() -> list[str]:
+    a = os.environ.get("MK20_ADB")
+    if not a:
+        raise NoAdb("set MK20_ADB (MK20-only adb wrapper, never the watch)")
+    return shlex.split(os.path.expanduser(a))
+
+
+def run_proc(cmd: list[str], timeout: float, env: dict | None = None) -> tuple[int, str, str]:
+    """subprocess with its own process group; on timeout the WHOLE group is killed (uv's python, mkadb pipelines)."""
+    try:
+        p = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True, env=env,
+                             start_new_session=True)
+    except OSError as e:
+        return 127, "", str(e)
+    try:
+        o, e = p.communicate(timeout=timeout)
+        return p.returncode, o, e
+    except subprocess.TimeoutExpired:
+        try:
+            os.killpg(p.pid, signal.SIGKILL)
+        except OSError:
+            pass
+        p.communicate()
+        return 124, "", "timeout"
+
+
+def sh(cmd: str, timeout: float = 20) -> tuple[int, str]:
+    rc, o, _ = run_proc(adb_cmd() + ["shell", cmd], timeout)
+    return rc, o
+
+
+def bridge_clients() -> int | None:
+    """Established TCP clients of the KD bridge (it serves ONE client and drops the old one on a new connect).
+    None = unknown (adb/netstat failed): callers must then NOT open a TCP connection."""
+    rc, o = sh("netstat -tn 2>/dev/null && echo NETSTAT_RC=0", timeout=10)
+    if rc != 0 or "NETSTAT_RC=0" not in o or "Proto" not in o:
+        return None
+    return sum(1 for l in o.splitlines() if l.startswith("tcp") and "ESTABLISHED" in l
+               and l.split()[3].endswith(f":{PORT}"))
+
+
+def bridge_listening() -> tuple[bool, bool]:
+    _, o = sh("netstat -ltn 2>/dev/null | grep ':%d '" % PORT, timeout=10)
+    return f"{DEV_IP}:{PORT}" in o, f"{LL_IP}:{PORT}" in o
+
+
+class Run:
+    def __init__(self, quiet: bool = False):
+        self.results: list[dict] = []
+        self.quiet = quiet
+
+    def check(self, name: str, ok: bool, detail: str = "") -> bool:
+        self.results.append({"check": name, "pass": bool(ok), "detail": detail})
+        if not self.quiet:
+            print(f"{'PASS' if ok else 'FAIL'} {name}{(' - ' + detail) if detail else ''}", flush=True)
+        return ok
+
+    @property
+    def ok(self) -> bool:
+        return all(r["pass"] for r in self.results)

+def loader_status() -> dict:
+    _, out = sh("sh /data/mk20/rescue/loader.sh status")

+    m = re.match(r"current=\S+ \d+ (\S+)", out)
+    d["current_v"] = m.group(1) if m else ""
+    d["raw"] = out.strip()
+    return d

+def health(v: str) -> dict:
+    _, out = sh(f"/data/mk20/releases/{v}/sbin/mk20d health", timeout=40)

+def wait_adb(present: bool, limit: float) -> bool:
+    end = time.time() + limit
+    while time.time() < end:
+        rc, out = sh("echo up", timeout=5)
+        if (rc == 0 and "up" in out) == present:
+            return True
+        time.sleep(3)
+    return False

+def do_reboot(run: Run) -> None:
+    _, up0 = sh("cut -d. -f1 /proc/uptime")
+    sh("touch /mnt/SDCARD/cmd-reboot && sync")
+    t0 = time.time()
+    run.check("reboot: device left USB", wait_adb(False, 120), f"{time.time() - t0:.0f}s")
+    run.check("reboot: adb back", wait_adb(True, 240), f"{time.time() - t0:.0f}s")
+    # wait for THIS boot's mk20d to confirm (the log still holds the previous boot's lines until the new "boot" line
+    # is written ~20 s in) and for the post-boot USB settling (adb re-add) to finish
+    end, done = time.time() + 300, False
+    probe = ("u=$(cut -d. -f1 /proc/uptime); c=$(awk '/mk20d boot /{c=0} /mk20d confirm /{c=1} END{print c+0}' "
+             "/data/mk20/logs/mk20d.log 2>/dev/null); echo \"$u $c\"")
+    while time.time() < end:
+        rc, o = sh(probe, timeout=10)
+        f = o.split()
+        if rc == 0 and len(f) == 2 and f[0].isdigit() and int(f[0]) >= 100 and f[1] == "1":
+            done = True
+            break
+        time.sleep(5)
+    run.check("reboot: mk20d confirmed this boot", done)
+    _, up1 = sh("cut -d. -f1 /proc/uptime")
+    run.check("reboot: fresh boot", up1.strip().isdigit() and up0.strip().isdigit() and int(up1) < int(up0),
+              f"uptime {up0.strip()} -> {up1.strip()}")
+    _, hr = sh("cat /data/mk20/state/hardreset.last")
+    run.check("reboot: clean FAT ro remount", "fat_ro=y" in hr and "mount_hung=n" in hr, hr.strip())

+def tcp_bound(host: str, iface: str | None) -> tuple[bool, str]:
+    if not iface:
+        return False, "no MK20 interface (refusing an unbound connect that could go via TUN)"
+    try:
+        t = tt.TcpTransport(host, PORT, 3, bound_if=iface)
+        src = t._s.getsockname()[0]
+        t.close()
+        return True, f"src {src}"
+    except OSError as e:
+        return False, str(e)
+
+
+def get_info(iface: str | None) -> tuple[bool, str]:
+    if not iface:
+        return False, "no MK20 interface (refusing an unbound connect)"
+    env = dict(os.environ, MK20_PORT=f"bound:{DEV_IP}:{PORT}:{iface}")
+    rc, o, e = run_proc(["uv", "run", "-q", "--with", "pyserial", "python", os.path.join(HERE, "mk20ctl.py"),
+                         "info"], 40, env=env)
+    m = re.search(r'"deviceVersion":\s*"([^"]+)"', o)
+    return bool(m), (m.group(1) if m else (o + e)[-200:] or f"rc={rc}")
+
+
+def hid_enumerated() -> bool:
+    _, out, _ = run_proc(["hidutil", "list"], 10)
+    return any(re.search(r"0x1d6b\s+0x104\s+\S+\s+1\s+6\s", l) for l in out.splitlines())
+
+
+def hid(run: Run) -> None:
+    run.check("hid: Mac enumerates 1d6b:0104 keyboard", hid_enumerated())
+    # Two ALL-RELEASED keyboard reports (report ID 1). The first write() returns once queued; the second completes only
+    # after the host read the first, so finishing proves the host polls the HID endpoint. Nothing is ever pressed, so a
+    # report left queued (host not polling) can't latch a key on the Mac. The writer runs detached and is never killed.
+    # [ -c ]: never create a regular file /dev/hidg0 when the HID function is absent (it would mask the real node).
+    # BusyBox here has no setsid/nohup: a subshell that ignores SIGHUP, with stdio detached, outlives the adb shell.
+    z = "'\\001\\000\\000\\000\\000\\000\\000\\000\\000'"
+    tag = f"{os.getpid()}-{int(time.time())}"
+    cmd = ("[ -c /dev/hidg0 ] || { echo NOHIDG; exit 0; }; "
+           "grep -qx configured /sys/class/udc/*/state || { echo NOTCONF; exit 0; }; "
+           "mkdir -p /tmp/mk20; mkdir /tmp/mk20/hidtap.busy 2>/dev/null || { echo HIDBUSY; exit 0; }; "
+           f"D=/tmp/mk20/hidtap.{tag}; "
+           f"( trap '' HUP; printf {z} > /dev/hidg0 && printf {z} > /dev/hidg0 && touch $D; rmdir /tmp/mk20/hidtap.busy ) "
+           "</dev/null >/dev/null 2>&1 & "
+           "i=0; while [ $i -lt 5 ] && [ ! -f $D ]; do sleep 1; i=$((i+1)); done; "
+           "[ -f $D ] && { rm -f $D; echo HIDOK; } || echo HIDPENDING")
+    _, o = sh(cmd, timeout=20)
+    det = next((k for k in ("HIDOK", "NOHIDG", "NOTCONF", "HIDBUSY", "HIDPENDING") if k in o), o.strip()[-80:])
+    run.check("hid: host consumes keyboard reports (all keys released)", det == "HIDOK", det)
+
+
