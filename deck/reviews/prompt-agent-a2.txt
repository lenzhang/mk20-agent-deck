ITEMS
1. src/rfb.{h,c}: RFB 3.8 client (accept 3.3/3.7 servers if cheap). Security type 2 VNC auth (DES, password truncated/padded to 8, bit-reversed
   key bytes per VNC convention; write a tiny self-contained DES or reuse a public-domain one — test vectors vs fakes/des.py), type 1 None.
   Reject anything else with a clear error (macOS Apple ARD type 30 → error "unsupported_security", do not implement).
   SetPixelFormat 32bpp true-colour little-endian; SetEncodings: ZRLE(16), Hextile(5), Raw(0), CopyRect(1), plus pseudo DesktopSize(-223),
   Cursor(-239, parse and discard). Full or incremental FramebufferUpdateRequest. Robust bounds checks: every rect must lie inside the fb;
   cap fb at 8192x8192 and reject larger; all reads with timeouts (connect 5 s, read 5 s; configurable); never trust lengths (reason strings,
   ServerCutText length capped, e.g. 1 MiB, excess skipped by streaming not allocated). Bell / SetColourMapEntries handled or rejected safely.
2. Streaming downscale (src/scale.{h,c}): the client must NOT hold a full-resolution framebuffer when the source is large (Retina 2880x1800 x4 =
   20 MB > budget). Design: keep a downscaled RGB888 target (default fit within 1280x800, keep aspect, area-average box filter, integer math) and
   accumulate decoded pixels from rects into per-target-pixel sums as tiles arrive (ZRLE 64x64 tiles / Hextile 16x16 / Raw rows), so peak memory is
   O(target + one tile row + zlib window). For a full-frame snapshot request (incremental=0) every source pixel arrives once; document that.
   CopyRect on a downscaled target: request a non-incremental refresh instead (or handle approximately) — document. Scale factor arbitrary (not
   only integer). Unit test: scaled output equals a Python reference box-filter of the fake gradient within ±2 per channel.
3. src/img.{h,c}: JPEG encode of the scaled RGB via stb_image_write (quality default 70, configurable), into a memory buffer with a hard cap
   (OAI_IMAGE_MAX 128 KiB from oai.h; if over, retry once at lower quality, then fail cleanly). Compile stb in its own TU with
   STBI_WRITE_NO_STDIO; silence only vendor warnings in that TU.
