配对这个浏览器

点下面的按钮后，键盘屏幕会显示 6 位配对码。本页不会显示配对码；配对码 5 分钟内有效，最多输错 5 次。

最多同时 2 个浏览器保持配对；用完后请在已配对的页面点“退出配对”。配对只在设备内存中保存：30 分钟无操作、12 小时或设备重启后需要重新配对。

设备状态

    模型

    模型商和模型列表来自固件内置目录（share/providers.json）。连接测试走已保存的网络线路，只说明能否连通。

    API 密钥

    密钥只写入设备（文件权限 0600），网页和接口都不会读回、显示或报告长度。vnc 一项是 Mac 屏幕共享密码。

    网络

    经 Mac 代理时依次尝试 — 的这个端口。代理失败不会改为直连；境外流量不允许直连。

    维护

    键盘程序：未知

    每个操作都会先请你确认，由键盘监督进程约 1 秒内处理。本页没有重启设备或回滚固件的按钮。

    权限与隐私

    本服务只在 USB 网卡（usb0）上提供，不加载任何外部资源。配对不会授予 agent 权限：agent 默认关闭，只能在键盘上实体允许。所有修改都需要已配对的会话和同源请求。
