## 1. 用户优先级（排序即取舍依据）

1. 语音输入（PTT）
2. 删除（修正听写）
3. 可以 / 不行（OK / NO）
4. 切换会话
5. 发送

据此：L1 不再放技能键（审 PR / 调试测试 / 重构 / 写文档），也不再放独立的接受 / 拒绝 / 发送 / 停止 / 聚焦 / 新会话键；
会话槽由 8 个增加到 15 个。

## 2. 键位（文档坐标：列 1..5 左→右，行 1..4 上→下；逻辑键号 fb = (行-1)×5 + 列）

### 2.1 L1（默认页）

```text
            列1        列2          列3              列4             列5
行1         S1         S2           S3               S4              S5
行2         S6         S7           S8               S9              S10
行3         S11        S12          S13              S14             S15
行4         PTT        ⌫ 删除       ⏎ 发送 / 可以     ✗ 不行 Esc       模式
            (fb16)     (fb17)       (fb18)           (fb19)          (fb20)
```

### 2.2 L4（K2 短按 L1↔L4；模式键长按 ≥600 ms 也进入）

```text
            列1        列2          列3              列4             列5
行1         DESK       HERD         TMUX             ＋新会话         回 L1
行2         S6         S7           S8               S9              S10
行3         S11        S12          S13              S14             S15
行4         PTT        ⌫ 删除       ⏎ 发送 / 可以     ✗ 不行 Esc       模式
```

- L4 第 2–3 行与 L1 **逐键同位同义**（同一会话在两页的同一物理键上），第 4 行与 L1 完全相同。
- L4 第 1 行：DESK / HERD / TMUX 直选模式（含不可用模式，置灰 + 原因，点选仍切换并回 L1）；
  ＋新会话 = 当前模式新建会话（cwd 只取选中会话已确认的项目路径），行为同旧「新会话」键；回 L1。
- S1–S5 不在 L4 上；L4 副屏注明「S1–S5 在 L1」（在 L1 上单击它们）。

### 2.3 每个键的含义

| 键 | 谁处理 | 行为 |
|---|---|---|
| S1..S15 会话槽 | Mac（mk20deck） | **单击 = 选中并置前**（窗口 / tmux 窗格到前台，口述和下面三个键就去这个会话）；**长按 ≥600 ms = 拿起（移动中）**，再点目标键放下（移到那里并钉扎，有会话则互换）、点自己 = 切换钉扎、K1 取消（§3.1） |
| PTT（fb16） | 键盘固件 USB HID | 按住 = 右 Option（IME 语音），松开 = 抬起；键面与 v1.3 相同（静态麦标 / 观察到按住时海绿波形） |
| ⌫ 删除（fb17） | 键盘固件 USB HID | Backspace，按住自动重复（修正听写） |
| ⏎ 发送 / 可以（fb18） | 键盘固件 USB HID | Return（发送输入框 / 回答「可以」） |
| ✗ 不行 Esc（fb19） | 键盘固件 USB HID | Escape（回答「不行」；也用于打断 Claude / codex） |
| 模式（fb20） | Mac | 短按（释放时判定）循环 Desktop → herdr → tmux → Desktop；长按 ≥600 ms 打开 L4 |

fb16–fb19 由键盘直接发到 Mac **当前前台窗口**，不经过 mk20deck：mk20deck 只画键面（图标 + 文字，
副行写明键盘发什么：「按住连删」「Return」「可打断 Claude/codex」），**不对这些键的事件做任何动作**
（固件不会转发；万一收到也直接丢弃，不改选中、不弹提示、不计长按）。

## 3. 手势（替换 v1.3 §6.3 手势表）

| 手势 | 会话槽 | 模式键 | 删除 / 发送·可以 / 不行 | PTT |
|---|---|---|---|---|
| 单击 | 按下即选中（副屏立即反馈），释放（<600 ms）时置前 | 释放时循环模式 | 键盘发 Backspace / Return / Escape | — |
| 双击 | **不再有双击手势**；每次单击都会再置前一次 | — | — | 不采用双击锁录 |
| 长按 ≥600 ms | **拿起（移动中）**，**不置前**，释放不再产生任何动作；随后按 §3.1 放下 | 打开 L4 并吞掉释放 | 删除键由键盘自动重复；其余无 | — |
| 按住 | — | — | — | 右 Option 按住 |

- 置前即原「聚焦」动作（Desktop `codex://threads/<id>`、tmux 窗格 + 终端 App、herdr `agent.focus`），
  成功后照旧本地清除「完成未读」提醒。
- 当前模式不能置前（如 tmux 未绑定 `terminal_app`）时，单击**只选中**，不每次弹 toast；副屏常驻
  「单击只选中 · 置前不可用：<原因>」。（2026-10-25 起 K1 按下本身不再置前、只回到最新，见 §4；唯一例外：
  Codex 桌面**开始回看**时仍会先置前该线程——helper 滚的是它的前台窗口。）
- PTT 按住期间单击会话只选中、不置前（§6.5「按住期间禁止置前」不变）。
- 按下到释放之间目标变化（按了别的会话键、目标消失、切模式）则释放不再置前。
- 空槽单击提示「空槽」，长按提示「空槽不可移动」；失联钉扎单击提示「失联钉扎 · 长按后点自己解除」，
  长按拿起后点自己解除（也可以拿起后放到别的槽，仍是失联钉扎）。
- **旧语义作废**：长按不再直接钉扎 / 取消钉扎；钉扎切换 = 长按拿起 + 点自己。
- 去掉：双击聚焦、聚焦键、停止键（长按停止 + 进度环）、接受 / 拒绝 / 发送键、四个技能键（含「＋新」降级角标与
  副屏「技能将在新线程预填…」说明）。L1 上的独立「新会话」键移到 L4 第 1 行。

### 3.1 拿起 / 放下（用户决策 2026-10-22）

长按会话槽 = 把它「拿起来」，下一次按会话槽 = 「放下」。只改排列，**任何一步都不置前、不改选中**
（长按的按下照旧选中该会话）。

| 当前状态 | 事件 | 结果 | 副屏 / 键面 |
|---|---|---|---|
| 空闲 | 长按会话槽 ≥600 ms（L1 S1..S15 或 L4 S6..S15） | 进入**移动中**（源 = 该槽）；释放不再做任何事 | toast「已拿起 Sn」；源键粉色虚线框（动画开时 4 fps 走动，关时静态虚线）+「移动中」角标代替状态条；副屏粉条「移动『<标题>』：点目标键放下 · 点自己=切换钉住 · K1 取消」 |
| 空闲 | 长按空槽 | 不进入移动中 | 「空槽不可移动」 |
| 移动中 | 按另一个会话槽（目标有会话） | 两者**互换**；被拿起的会话在目标位置**钉扎**；被换走的会话在源位置保留自己的钉扎 / 失联标志 | 「已与 Sm 交换 · 已钉扎」 |
| 移动中 | 按另一个会话槽（目标空） | 移到目标并**钉扎**；源槽变空（之后按常规补位规则可能被填） | 「已移到 Sm · 已钉扎」 |
| 移动中 | 按源槽自己 | **切换钉扎**（未钉 → 钉；已钉 → 取消；失联钉扎 → 解除） | 「已钉扎」/「已取消钉扎」/「已解除失联钉扎」 |
| 移动中 | K1 按下 | 取消，什么都不变；这次 K1 不置前、按住也不进 L4 | 「已取消移动」 |
| 移动中 | 8 s 内没有任何键 / 旋钮事件（旋转也算事件，会重新计时） | 取消，什么都不变 | 「已取消移动」 |
| 移动中 | 换页 / 换模式：K2 短按或长按、模式键短按或长按、L4 第 1 行任一键（DESK / HERD / TMUX / ＋新会话 / 回 L1）、任何模式切换 | 取消，什么都不变；按键本身照常生效（换页 / 换模式 / 新建会话） | 「已取消移动 · <原提示>」，如「已取消移动 · 切到 L4」 |
| 移动中 | 源会话消失（轮询发现源槽已不是它） | 取消 | 「已取消移动：会话已消失」 |
| 移动中 | 断线重连 / 系统或显示器唤醒 | 取消（与进行中的按键一起丢弃，不重放） | 「已取消移动」 |
| 移动中 | PTT / 删除 / 发送·可以 / 不行（键盘侧 HID） | 忽略：不放下、不取消、不重新计时（固件本来就不转发） | — |

- 放下的那一次按键在**按下时**生效；它的释放不再置前，按住超过 600 ms 也不会再次拿起。
- 立即写状态文件（`state.json`，与其他槽位变化相同）；每模式独立的槽位记忆不变（移动只作用于当前模式）。
- 黏性 / 替换规则不变，用户放下的位置靠**钉扎**受保护：轮询不会重排或替换它；被换走或留空的槽照常参与补位与
  溢出替换。
- L4 第 2–3 行就是 L1 的 S6..S15：在 L4 上拿起、放下与在 L1 上完全相同；跨页（拿起后按 K2 换页）会取消。

### 3.2 选项模式（用户决策 2026-10-22）

在 L1 上**单击**一个「待输入 / 待审批」会话，且该状态来自 **hook 记录**（tmux 里的 Claude / codex；
Codex 桌面、herdr 永不进入，集成方决定 2026-10-22），窗口**确实已置前**（适配器确认成功；不能置前、PTT 按住、
L4 上都不进入）时，键盘进入选项模式，用数字键回答该 agent 的编号选择：

```
第 1 行: [1 …] [2 …] [3 …] [4 …] [5 …]   ← 只有选项（有标签就写标签）
第 2 行: 空
第 3 行: 空                               ← 清空会话列表，一眼看出这是在作答
第 4 行: PTT | 删除 | 发送·可以 | 不行 Esc | 模式（不变）
```

- 选项个数 N = 1..5，只画 N 个键（琥珀底大数字 + 标签），其余为暗键。标签来源：Claude AskUserQuestion →
  hook 记录的选项标签（第一个问题，≤5 个 × 24 字）；权限确认（PermissionRequest / permission_prompt，含 codex）→
  固定「1 是」「2 是，且不再问」「3 否」；其他未知 → 只显示数字 1..5。
- 副屏：会话标题 + 琥珀条「选项：按 1–N 选择 · × 取消 · K1 返回」（Mac 字体没有 ✗ 字形，用 ×）。
- 按选项键 k：**键盘自己**向 Mac 前台窗口发 USB HID 数字 k（usage 0x1E..0x22），**按下即发「按下+抬起」**
  （按住也只打一个数字，不会被 macOS 自动重复；松开不再发 HID），同时把这次按键标记 `hid` 转发给 Mac；
  Mac 只做反馈：toast「已选 k」，保持到会话状态改变或 3 s 后回到会话列表。
- 按住说话（PTT，右 Option）按住时按数字键：键盘**忽略**（不发数字，Option+数字会打出符号），转发标记
  `ignored:"ptt"`，副屏 toast「先松开按住说话」；删除 / 发送 / 不行 与 PTT 的组合不变。
  「发送·可以」（Return）同样反馈「已确认」；「不行 Esc」由键盘发 Escape，Mac 收到标记即退出（「已取消选择」）。
- 退出（回到会话列表）：会话离开 needs_*（已作答 → 运行中等）、Esc、K1 按下（不置前、不进 L4）、点暗键、
  换页 / 换模式（K2、模式键、L4、设置页）、30 s 无键 / 旋钮输入、选择后 3 s、断线重连 / 唤醒。
- **长按批准（1.8.1，2026-10-29）**：权限确认的「1 是」「2 是，且不再问」不再按下即发：这两个键不在 `ui.hidKeys`
  映射里（键盘按普通键转发），Mac 计时，按住满 `[deck] approve_hold_s` 后**收到对应抬起**（默认 1 s，0 = 旧行为）才用
  `tmux send-keys -t <会话窗格> -l <k>` 把数字打进该会话自己的窗格；键面进度环，成功后键闪绿 + 打勾 + 可选提示音
  （`approve_sound`）。早松开 = 不批准（副屏「未批准：需按住 1 秒」）；达到时长后松开才提交。触发前重新核对：仍在该会话的选项模式、仍是权限
  提示、仍在 L1 同一模式、未按住说话、窗格不在 copy mode；任一不满足就不发。超时、断线 / 唤醒（丢弃按键）永不批准。
  「3 否」、不行 Esc 仍立即生效。只在适配器声明能直接作答（`capabilities().approve is None`，即 tmux）时启用。
  选项模式中转 K1 不回看（提示「选项中不回看 · 按 K1 返回会话列表」：数字要进提示框，不能让窗格进 copy mode）；
  选项键与暗键不选中、不置前、不拿起（长按也不）。
- 协议：Mac 进入时（在显示选项的那一帧**之前**）发 `ui.hidKeys`（fb1..fbN → 数字），每 10 s 刷新，退出时发 `{}`；
  键盘 30 s 无刷新、任何换页 / `ui.hello` / 断线 / SUSPECT / 急停都会自行清除。旧固件（hello 无 `ui.hidKeys`
  能力或回复 unsupported）→ 照样显示选项，副屏红字「固件不支持数字键，请在 Mac 上按数字」，按选项键只提示。
  映射被拒（如键盘页面未就绪）→ 每 1 s 重试，副屏提示「数字键暂未生效…」。细节见 `deck/kbd/UI.md`「L1 option mode」。
- 隐私：hook 记录只多存选项标签（AskUserQuestion）或 `prompt_kind: "permission"`，下一次状态变化即清除；
  从不存问题正文、prompt、其他工具参数、通知正文或 transcript 路径。

## 4. 旋钮

- **K1（用户决定 2026-10-25，取代原「转 = 按待处理顺序移动选中、按 = 置前」）**：
  - 转 = **回看选中会话的对话历史**：逆时针 = 更早（上翻），顺时针 = 更新（下翻）；每格 3 行，快转（间隔 < 0.12 s）
    逐步加速到每格 15 行；不改选中。没有回看时顺时针只提示「已是最新」。
  - 按 = **回到最新内容**并退出回看。**移动中按 K1 = 取消移动**、**选项模式中按 K1 = 回到会话列表**（都不回到最新）。
  - 长按 ≥600 ms 进 L4（固件 ui.page 起由键盘自己判定 1 s）；L4 上短按 = 设置页（固件本地）。
  - tmux：只操作选中会话的窗格（copy mode：`copy-mode -e` + `send-keys -X -N n scroll-up/down`，按 = `cancel`），
    不动鼠标、不抢焦点。Codex 桌面：先置前该线程，再由单独签名的 helper `mk20deck-scroll`（只有它需要 macOS
    辅助功能授权，`mk20deck scroll-setup` 安装并请求授权）向 Codex 窗口发滚轮事件；未授权时副屏提示一次
    「回看需要辅助功能授权：运行 mk20deck scroll-setup」。herdr：不支持。
  - 副屏：回看中蓝条「回看中 · 按 K1 回到最新」。结束：按 K1、选别的会话 / 单击会话键、切模式、观测到按住说话、
    会话消失、2 分钟不转 K1（tmux 退出 copy mode；Codex 桌面只去掉提示，不会自己把 Codex 拉到前台）。
    按住说话时不回看。
- **K2**：转 = 滚动副屏摘要（不改选中）；短按 = L1↔L4；长按 ≥600 ms 回 L1。

## 5. 槽位：8 → 15

- 每模式独立 15 槽；槽位编号 S1..S15 = 第 1–3 行从左到右、从上到下（索引 i → 列 i%5+1、行 i//5+1）。
- 黏性规则不变：首次按 Priority 填槽，之后已占槽不因状态变化重排；Priority 只用于空槽补位与溢出替换；
  钉扎与当前选中为保护槽；候选者须**严格高于**最低非保护槽才替换；超过 15 个时副屏 `+N`（含「N 待处理」）。
- 跨模式待处理计数（副屏顶部「tmux 2 待处理」、模式键 / L4 模式键角标）按全部会话统计，不受槽数影响。
- **状态文件迁移**：旧状态文件（每模式 8 槽、无 `n_slots` 字段）按**物理位置**迁移——旧 A1..A4（第 1 行
  第 1–4 列）→ S1..S4，旧 A5..A8（第 2 行第 1–4 列）→ S6..S9；钉扎、选中、排除项保留；S5、S10 及第 3 行为空，
  下次轮询按规则补位。新文件写 `"n_slots": 15`。

## 6. 副屏
