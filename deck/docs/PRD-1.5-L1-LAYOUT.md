# PRD 1.5 增量：L1 / L4 新键位（待并入 PRD v1.5）

- **决策人 / 日期**：用户，2026-10-21。
- **范围**：替换 PRD v1.3 §6.2（L1 主页键位、L4 确定键位）与 §6.3（选中模型与手势）中关于 L1/L4 的部分；
  其余条款不变，受影响处见文末「连带修改」。由集成方合并进 PRD v1.5。
- **实现**：Mac 端 mk20deck（`deck/mk20deck`，分支 `feature/l1-layout-v2`）。键盘固件侧（`deck/kbd`）另行实现，
  须满足下文「固件侧须配合」。

## 1. 用户优先级（排序即取舍依据）

1. 语音输入（PTT）
2. 删除（修正听写）
3. 可以 / 不行（OK / NO）
4. 切换会话
5. 发送

据此：L1 不再放技能键（审 PR / 调试测试 / 重构 / 写文档），也不再放独立的接受 / 拒绝 / 发送 / 停止 / 聚焦 / 新会话键；
会话槽由 8 个增加到 15 个。

## 2. 键位（文档坐标：列 1..5 左→右，行 1..4 上→下；逻辑键号 fb = (行-1)×5 + 列）

### 2.1 L1（默认页）

```text
            列1        列2          列3              列4             列5
行1         S1         S2           S3               S4              S5
行2         S6         S7           S8               S9              S10
行3         S11        S12          S13              S14             S15
行4         PTT        ⌫ 删除       ⏎ 发送 / 可以     ✗ 不行 Esc       模式
            (fb16)     (fb17)       (fb18)           (fb19)          (fb20)
```

### 2.2 L4（K2 短按 L1↔L4；模式键长按 ≥600 ms 也进入）

```text
            列1        列2          列3              列4             列5
行1         DESK       HERD         TMUX             ＋新会话         回 L1
行2         S6         S7           S8               S9              S10
行3         S11        S12          S13              S14             S15
行4         PTT        ⌫ 删除       ⏎ 发送 / 可以     ✗ 不行 Esc       模式
```

- L4 第 2–3 行与 L1 **逐键同位同义**（同一会话在两页的同一物理键上），第 4 行与 L1 完全相同。
- L4 第 1 行：DESK / HERD / TMUX 直选模式（含不可用模式，置灰 + 原因，点选仍切换并回 L1）；
  ＋新会话 = 当前模式新建会话（cwd 只取选中会话已确认的项目路径），行为同旧「新会话」键；回 L1。
- S1–S5 不在 L4 上；L4 副屏注明「S1–S5 在 L1」，K1 旋转仍可选到它们。

### 2.3 每个键的含义

| 键 | 谁处理 | 行为 |
|---|---|---|
| S1..S15 会话槽 | Mac（mk20deck） | **单击 = 选中并置前**（窗口 / tmux 窗格到前台，口述和下面三个键就去这个会话）；长按 ≥600 ms = 钉扎 / 取消钉扎 |
| PTT（fb16） | 键盘固件 USB HID | 按住 = 右 Option（IME 语音），松开 = 抬起；键面与 v1.3 相同（静态麦标 / 观察到按住时海绿波形） |
| ⌫ 删除（fb17） | 键盘固件 USB HID | Backspace，按住自动重复（修正听写） |
| ⏎ 发送 / 可以（fb18） | 键盘固件 USB HID | Return（发送输入框 / 回答「可以」） |
| ✗ 不行 Esc（fb19） | 键盘固件 USB HID | Escape（回答「不行」；也用于打断 Claude / codex） |
| 模式（fb20） | Mac | 短按（释放时判定）循环 Desktop → herdr → tmux → Desktop；长按 ≥600 ms 打开 L4 |

fb16–fb19 由键盘直接发到 Mac **当前前台窗口**，不经过 mk20deck：mk20deck 只画键面（图标 + 文字，
副行写明键盘发什么：「按住连删」「Return」「可打断 Claude/codex」），**不对这些键的事件做任何动作**
（固件不会转发；万一收到也直接丢弃，不改选中、不弹提示、不计长按）。

## 3. 手势（替换 v1.3 §6.3 手势表）

| 手势 | 会话槽 | 模式键 | 删除 / 发送·可以 / 不行 | PTT |
|---|---|---|---|---|
| 单击 | 按下即选中（副屏立即反馈），释放（<600 ms）时置前 | 释放时循环模式 | 键盘发 Backspace / Return / Escape | — |
| 双击 | **不再有双击手势**；每次单击都会再置前一次 | — | — | 不采用双击锁录 |
| 长按 ≥600 ms | 钉扎 / 取消钉扎，**不置前**，释放不再产生点击 | 打开 L4 并吞掉释放 | 删除键由键盘自动重复；其余无 | — |
| 按住 | — | — | — | 右 Option 按住 |

- 置前即原「聚焦」动作（Desktop `codex://threads/<id>`、tmux 窗格 + 终端 App、herdr `agent.focus`），
  成功后照旧本地清除「完成未读」提醒。
- 当前模式不能置前（如 tmux 未绑定 `terminal_app`）时，单击**只选中**，不每次弹 toast；副屏常驻
  「单击只选中 · 置前不可用：<原因>」。K1 按下（显式聚焦）仍会提示原因。
- PTT 按住期间单击会话只选中、不置前（§6.5「按住期间禁止置前」不变）。
- 按下到释放之间目标变化（K1 改选、目标消失、切模式）则释放不再置前。
- 空槽单击提示「空槽」；失联钉扎单击提示「失联钉扎 · 长按解除」，长按解除。
- 去掉：双击聚焦、聚焦键、停止键（长按停止 + 进度环）、接受 / 拒绝 / 发送键、四个技能键（含「＋新」降级角标与
  副屏「技能将在新线程预填…」说明）。L1 上的独立「新会话」键移到 L4 第 1 行。

## 4. 旋钮（不变，仅改措辞）

- **K1**：转 = 按「待审批 > 待输入 > 出错 > 完成未读 > 其余按槽位」移动选中（15 槽全部参与）；按 = 置前选中会话
  （与单击会话键相同）；长按 ≥600 ms 进 L4；L4 上短按 = 设置页（固件本地）。
- **K2**：转 = 滚动副屏摘要（不改选中）；短按 = L1↔L4；长按 ≥600 ms 回 L1。

## 5. 槽位：8 → 15

- 每模式独立 15 槽；槽位编号 S1..S15 = 第 1–3 行从左到右、从上到下（索引 i → 列 i%5+1、行 i//5+1）。
- 黏性规则不变：首次按 Priority 填槽，之后已占槽不因状态变化重排；Priority 只用于空槽补位与溢出替换；
  钉扎与当前选中为保护槽；候选者须**严格高于**最低非保护槽才替换；超过 15 个时副屏 `+N`（含「N 待处理」）。
- 跨模式待处理计数（副屏顶部「tmux 2 待处理」、模式键 / L4 模式键角标）按全部会话统计，不受槽数影响。
- **状态文件迁移**：旧状态文件（每模式 8 槽、无 `n_slots` 字段）按**物理位置**迁移——旧 A1..A4（第 1 行
  第 1–4 列）→ S1..S4，旧 A5..A8（第 2 行第 1–4 列）→ S6..S9；钉扎、选中、排除项保留；S5、S10 及第 3 行为空，
  下次轮询按规则补位。新文件写 `"n_slots": 15`。

## 6. 副屏

- 继续显示选中会话（头像 / 名称 / 状态 / effort / 摘要），L4 上也显示。
- 未选中提示改为「单击会话键：选中并置前 · 长按钉扎 · 转 K1 挑待处理」（原「单击 Agent 键选中；双击/聚焦键置前」作废）。
- 原「技能键：技能将在新线程预填，不进入当前会话」删除；该行改为上文的「置前不可用」说明（仅在不能置前的模式）。
- L4：「钉扎 n/15 · 长按槽位钉扎/解除 · S1–S5 在 L1」。

## 7. 兼容与保留

- 适配器的 `send()` / `stop()` / `skill()` 及能力字段保留（不再绑定任何键），便于以后放回 L2/L3。
- `config.toml` 的 `[[skills]]` 照常读入（格式错误也只告警、不致命），不绑定任何键。
- 审批代答（v1.3 §6.3「危险操作」接受 / 拒绝 P1）在 L1 上不再有专用键：「发送 / 可以」「不行 Esc」是普通
  Return / Escape，作用于前台窗口的原生 UI，不经 mk20deck、不绑 requestId。P1 若恢复代答需另定键位。

## 8. 固件侧须配合（`deck/kbd`，另行实现）

| 逻辑键 | L1 / L4（主机页在线） | 说明 |
|---|---|---|
| fb16 | 右 Option 按住 / 抬起（现状不变） | 不转发给 Mac |
| fb17 | **Backspace**，按住自动重复 | 不转发给 Mac |
| fb18 | **Return** | 不转发给 Mac |
| fb19 | **Escape** | 不转发给 Mac（HOME/LS 上 fb19 仍是「网页设置」） |
| fb20 | 键盘智能体未启用时转发给 Mac（模式键，现状不变） | 智能体启用时仍为急停 |
| fb1..fb15 | 转发给 Mac | — |

- **L4 本地「回 L1」键须从 fb14 移到 fb5**：现固件在 L4 把 fb14 当本地返回键（`onboard.c` 中
  `o->route == ONBOARD_L4 && fb == 14`）；新键位 fb14 是会话 S14，fb5 才是「回 L1」。
- 键面：fb16 仍由固件在 L5 / 智能体页保留；L1/L4 上 fb17–fb19 的键面是 Mac 画的主机内容（与其他主机键相同），
  主机页不在线（占位页）时由固件决定是否仍发 HID 及占位文字。
- 释放与安全：与 PTT 相同的按下时归属规则（按下时在哪页，抬起就发给谁）；急停 / 断线 / 离开主机页时补发抬起，
  不残留 Backspace 自动重复。

## 9. 验收（Mac 端，已实现的自动化测试）

- L1 / L4 全部 20 键角色表；L4 第 2–4 行与 L1 同位同义；fb16–fb20 编号与底行角色一致。
- 单击 = 选中 + 置前（按下选中、释放置前、长按只钉扎不置前、每次单击都置前、目标中途变化不置前、
  不能置前的模式只选中并有副屏说明、PTT 按住时不置前）。
- 15 槽填满 / 黏性 / 严格高于替换 / `+N` 溢出 / 全保护时只更新溢出；旧 8 槽状态文件按物理位置迁移。
- 删除 / 发送·可以 / 不行 键事件在 L1、L4 上被忽略（无动作、无提示、无长按、不改选中、不重绘）。
- 模拟器截图：`python -m mk20deck sim-shots --scenario layout --out <dir>`。
